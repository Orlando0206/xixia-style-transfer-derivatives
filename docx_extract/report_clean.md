| **2.3 国内外研究现状和发展动态**                                                                                                                                                                                                                                                                                                                                                                                                                                  |

| 2.3.1 图像风格迁移                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 国外风格迁移的研究起点可追溯到 Gatys 等人^\[1\]^于 2016 年在《A Neural Algorithm of Artistic Style》中的工作：利用预训练 VGG 网络分别提取内容图与风格图的卷积特征，以特征图均方误差度量内容差异、以 Gram 矩阵度量风格相关性，通过从内容图初始化并迭代优化生成图，首次实现将任意艺术风格迁移到任意内容图像，奠定了神经风格迁移的理论范式。针对其逐张优化计算昂贵的问题，Johnson                                                                                    |
| 等人^\[2\]^提出基于感知损失的前馈快速风格迁移，将迁移转化为一次前向推理实现实时化；Ulyanov 等人^\[3\]^提出的实例归一化进一步简化了前馈网络训练。此后研究转向任意风格与多风格：Huang 与 Belongie^\[4\]^提出自适应实例归一化（AdaIN），通过逐通道对齐统计量使单一网络迁移任意风格；Li 等人^\[5\]^提出白化-着色变换（WCT）实现更精细的风格匹配；针对成对数据限制，Zhu 等人^\[6\]^提出                                                                                |
| CycleGAN，借助循环一致性损失在无配对图像上完成域间转换。近年来生成对抗网络与扩散模型的引入进一步提升了                                                                                                                                                                                                                                                                                                                                                            |
+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| 纹理细节与生成质量。                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 国内学者在风格迁移的轻量化与文化应用方面开展了大量工作。薛楠等人^\[7\]^针对 VGG 损失网络参数冗余问题，采用点卷积与深度卷积替换标准卷积并删减冗余层，降低约 15.8% 的计算复杂度；李美丽等人^\[11\]^将语义分割引入风格迁移，缓解了跨语义区域的错误迁移。在文化图像风格化应用方面，贵向泉等人^\[8\]^提出融合 CBAM 注意力机制的循环生成对抗网络方法，提升敦煌壁画纹理与色彩还原能力；张梦雪等人^\[9\]^将风格迁移应用于壮锦纹样衍生设计；丁炜航等人^\[10\]^研究了基于   |
| AIGC 的传统服饰纹样数字化创新路径；胡明涛等人^\[12\]^系统梳理了从优化式方法向快速前馈、任意风格迁移演进的整体趋势。                                                                                                                                                                                                                                                                                                                                               |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 2.3.2 图像修复（图像补全）                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 国外传统图像修复方法分两类：一类是基于偏微分方程的扩散式方法，由 Bertalmio 等人^\[13\]^于 2000 年开创，通过沿等照度线方向将邻域信息扩散到缺失区域；另一类是基于样本块匹配的方法，由 Criminisi 等人^\[14\]^提出，通过搜索相似纹理块填充缺失区域。Telea^\[15\]^提出的快速行进法从破损边界由外向内逐层推进，因实现简单、速度快而被 OpenCV 等开源库广泛集成。随着深度学习发展，Pathak 等人^\[16\]^提出 Context Encoder，首次以卷积自编码器端到端生成缺失内容；Iizuka  |
| 等人^\[17\]^提出全局-局部判别器（GLCIC）同时约束局部纹理与全局一致性；针对不规则孔洞，Liu 等人^\[18\]^提出部分卷积，Yu 等人^\[19\]^提出门控卷积实现自由形状修复；Nazeri 等人^\[20\]^提出 EdgeConnect，先补全边缘结构再填充颜色，显著改善大面积修复的结构合理性。                                                                                                                                                                                                  |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 国内图像修复研究多与文化保护场景结合：在敦煌壁画、古画与老照片修复方面，研究者将注意力机制、生成对抗网络与语义先验引入修复模型，用于处理壁画剥落、颜料褪色、裂纹与噪点等典型病害；同时面向文化遗产的修复强调"修旧如旧"，催生了针对文物图像的专用修复方法。                                                                                                                                                                                                        |
